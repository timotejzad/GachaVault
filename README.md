# GachaVault

GachaVault je spletna aplikacija za osebno spremljanje pullov v igrah Honkai: Star Rail in Wuthering Waves. V enem uporabniškem računu združuje zgodovino pullov, spremljanje pityja, zagotovila, statistiko, zbirko karakterjev ter koledar bannerjev.

## Tehnologije

| Del projekta | Tehnologije |
| --- | --- |
| Frontend | React, Vite, CSS |
| Backend | Node.js, Express, REST API |
| Podatkovna baza | MongoDB Atlas, Mongoose |
| Avtentikacija | JWT tokens |
